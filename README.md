# UPS Activity System Quick Card

## Features

- Fill Timecard with one click
- Create and manage multiple schedules
- Export all schedules to JSON file
- Import schedules from JSON file
- Delete saved schedules
- Saves schedules locally in the browser
- Supports automatic updates through GitHub/Tampermonkey

## Installation

1. Install Tampermonkey from Chrome Web Store.
2. Manage Extension > Allow User Scrips.
3. Click on ups-timecard-quickcard.user.js link in this GitHub Repo
4. Click RAW button and Tampermonkey will automatically ask you if you want to import script
5. Navigate to UPS Activity System.
6. Configure your schedule.

## Updating

Updates are automatically detected by Tampermonkey.
