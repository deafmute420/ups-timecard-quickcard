# UPS Activity System Quick Card

## Features

- Fill Timecard
- Configure Schedule
- Export Schedule
- Import Schedule
- Reset Schedule

## Installation

1. Install Tampermonkey from Chrome Web Store.
2. Manage Extension > Allow User Scrips.
3. Open the userscript file.
4. Install the script.
5. Navigate to UPS Activity System.
6. Configure your schedule.

## Updating

Updates are automatically detected by Tampermonkey.
